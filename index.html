จัดการข้อมูล

ข้อมูลเก็บไว้ในเบราว์เซอร์เครื่องนี้ (localStorage) ควรส่งออกไฟล์สำรองไว้ด้วย การล้างข้อมูล Safari อาจทำให้ข้อมูลหายได้

วิธีใช้และข้อควรรู้

1. เริ่มเที่ยว กรอกเลขไมล์และกดเริ่มเที่ยว
2. ผ่านจุดสำคัญแต่ไม่ได้จอด: กด “บันทึกจุด” (กรอกเลขไมล์ใหม่เพื่อคำนวณระยะทางช่วงนั้น)
3. หยุดรถ: กด “จอดพัก” และเมื่อออกกด “ออกเดินทางต่อ” โดยไม่ต้องสร้างจุดซ้ำ
4. ถึงปลายทาง: กรอกเลขไมล์ปลายทางแล้วกด “สิ้นสุดเที่ยว”

การจับ GPS ต้องอนุญาตตำแหน่งและใช้ HTTPS (เช่น GitHub Pages) หรือ localhost การแปลงพิกัดเป็นชื่อสถานที่ต้องเชื่อมต่ออินเทอร์เน็ต หากค้นชื่อไม่ได้จะเก็บพิกัดแทน ตัวเลข GPS ระหว่างจุดไม่ใช่ระยะทางตามถนนจริง จึงใช้เลขไมล์รถในการคำนวณระยะทาง
